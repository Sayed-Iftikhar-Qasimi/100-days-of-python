# 100 Days of Python 🐍

My journey through **"100 Days of Code: The Complete Python Pro Bootcamp"** by Dr. Angela Yu, building one Python project at a time — from beginner fundamentals to advanced, real-world applications.

## **About This Repo**

This repository documents my progress through the course, with each project built, tested, and pushed as I complete it. The goal isn't just to finish the course, but to genuinely understand the concepts behind each project and build strong, independent programming skills.

## **Skills Practiced So Far**

- Core syntax: variables, data types, indentation, f-strings
- Control flow: if/elif/else, while loops, for loops
- Data structures: lists, dictionaries, indexing
- Functions: parameters, return values, scope
- The `random` module: `choice()`, `shuffle()`, `randint()`, `sample()`
- The modulo operator (`%`) for wraparound logic
- Debugging: IndexError, logic errors, off-by-one errors
- Clean code: refactoring into functions, two-pass writing (make it work → make it clean)
